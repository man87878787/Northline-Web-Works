# Security and privacy

- **All files published on this branch are PUBLIC.** Never put passwords, API keys, access tokens, private keys, personal addresses, private emails, private account records, or confidential information into files, README content, issue descriptions or commit messages.
- This project collection is designed to function completely in a browser with no server, authentication, analytics, telemetry, third-party libraries, or remote API calls.
- The bundled input examples are synthetic. Your text and numerical inputs are handled in your local browser; these apps are not designed to send them anywhere.
- Avoid entering actual credentials in any publicly hosted app, even when an app claims local-only processing.
- Before every future publish, review diffs and scan for secrets and personal information. If anything sensitive is accidentally committed, remove it promptly and rotate the affected credentials; deleting a commit alone may not erase exposed data from history or caches.
- Browser and accessibility behavior still require broader hands-on testing.
