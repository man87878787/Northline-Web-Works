# 100 Useful Browser Apps

This branch contains a collection of **100 distinct offline-first single-page HTML projects** in `hourly-lab/projects/`.

## Get started

1. Download this branch as a ZIP from GitHub (Code → Download ZIP).
2. Extract the files.
3. Open `hourly-lab/index.html` in a web browser.
4. Search or filter to find an app; click the app to open it.

If your browser restricts local-file linking, you can open the individual `projects/<slug>/index.html` file directly, or serve the folder from a local static web server.

## Layout

- `hourly-lab/index.html` — searchable local directory.
- `hourly-lab/INDEX.md` — human-readable master list.
- `hourly-lab/catalog-part-1.json` through `catalog-part-4.json` — machine-readable catalog.
- `hourly-lab/projects/<slug>/index.html` — each standalone tool.
- `hourly-lab/CHANGELOG.md` — additions and maintenance notes.
- `hourly-lab/SECURITY.md` — handling public repositories and credentials.

## Scope and limits

All browser tools are small self-contained prototypes for everyday uses. Some deal with financial estimates or engineering math and should be double-checked before any important use. Demo-input smoke tests passed during creation; automated cross-browser tests have not yet been performed. No login, external API, or server is needed for these tools. Project code is published publicly; do not enter real credentials into untrusted code or commit private data.
