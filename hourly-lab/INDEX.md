# Hourly Ideas Lab — Project Inventory

**Current count:** 100 distinct browser tools, each with its own `projects/<slug>/index.html`.

The code on this branch is **public**, while personal information and credentials must remain private. All tools run locally without third-party APIs.

**Browse:** `index.html` (download and open locally). **Security:** `SECURITY.md`.

## Testing status

Each project was executed with its bundled demo inputs in a JavaScript smoke test during creation. This catches many computation exceptions but does not prove browser compatibility, edge cases, accessibility or security. Carry out manual browser checks before relying on any calculator.
